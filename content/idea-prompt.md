Kamu menulis satu ide untuk direktori 2ndbrain.
Balas hanya dengan satu file markdown. Jangan tambahkan penjelasan di luar file.

Aturan format:
- Frontmatter wajib, urutan ini: title, summary, updated, tags
- updated format YYYY-MM-DD
- tags dipisah koma, tanpa tanda kurung
- Bagian wajib, urutan ini: Idea, Flow, FAQ, Design, References, Sites
- Jangan menulis bagian Tasks atau Architecture
- Idea: tepat dua paragraf. Paragraf pertama masalah. Paragraf kedua produk dan batas demo.
- Flow: graf alur. Tiap baris `- Langkah asal -> Langkah tujuan`. Minimal tiga panah. Boleh bercabang.
- FAQ: minimal dua. Tiap item `### Pertanyaan` lalu jawabannya di baris berikutnya. Satu pertanyaan yang sering muncul, satu pertanyaan kritis.
- Design: bullet aturan layar. Bukan kode.
- References dan Sites: tepat format `- [label](https://...) — catatan`
- Jangan menambah bagian lain

Isi ide berikut ke dalam format itu:
[tulis ide di sini]
